# App influence moodboard (beyond Ultrahuman)

Reference map for product and design passes. Steal patterns, not brands. Diabeaters stays educational wellness — not clinic software and not biohacker denseness.

Already shipped from **Ultrahuman**: glanceable LIVE strip (`app-status-strip.tsx`), one-number + one calm sentence hero (`buildHomeHeroNarrative`).

## Surface map

| Diabeaters surface | Primary influence | Steal | Avoid |
| --- | --- | --- | --- |
| Home LIVE strip + next-best strip | Ultrahuman | One primary action; glanceable status | Dashboard clutter |
| Home bedtime due / bedtime moment | **Oura** | Soft evening surface; readiness language (“why” in plain English); restorative indigo, not alarm red | Magical medical “score” |
| Home glucose empty / connected | **Levels** | Education-first empty chart; green in-range band as story; one clear connect CTA | Endless metrics |
| Patterns / meal adviser blurbs | Levels | Short “what this means” copy; in / above / below range | Judgemental “good/bad” sugar |
| Supporter Mode home | **Gluroo** | Shared-context hierarchy; “what they shared”; one primary carer action | Surveillance vibe; push guilt |
| Treated hypo / meal / supply top-up | **mySugr** (lightly) | Light, rewarding log shortcuts | Monster gamification / moralising |
| Help Now / night calm | **Sugarmate** | Simple peace-of-mind alerts; quiet night framing | Clinic report dumps |
| App shell atmosphere | Flo (already) | Soft mesh, intimate calm | Cold clinical grey |
| Post-exercise / travel focus | Whoop (lightly) | Optional insight cards | Strain anxiety |
| CGM Settings connect | Tidepool / Loop | Trustworthy data-integration mental model | DIY Nightscout denseness on Home |
| Feed + Beatie | One Drop / Headspace (tone) | Peer warmth; supportive empty states | Medical forum / competition on glucose |

## Experiment checklist

1. **Oura × bedtime** — readiness subline on next-best; softer indigo surface; bedtime moment copy.
2. **Levels × CGM** — education-first empty/connected copy on Home glucose panel.
3. **Gluroo × supporter** — “Shared with you” hierarchy; fewer competing CTAs; clearer shared-context framing.

Constraint: keep Ultrahuman’s **one primary next action** on Home so new influences do not reintroduce a widget dashboard.
